## 五个思维模型

1. **Jacobian 是当前姿态下的局部速度地图。** 输入关节小速度，输出工具小速度；地图随姿态改变，不能当作全局路径规划器。
2. **主任务与次级任务共享一套执行能力。** 理想几何上可以分解方向，经过限幅和电机后仍需重新检查实际主任务。
3. **一回合是一份有时钟的合同。** 参考时钟不停，成功必须在整个时间区间满足约束，最后到终点不够。
4. **可行 witness 是实际存在的执行证据。** 重放通过能证明特定模拟条件下有一条解；搜索失败不证明无解，生成方法也可能筛偏任务集。
5. **实验比较依赖同等机会与未见数据。** 强基线、共享接口、验证选参、冻结测试和完整失败记录共同决定结论可信度。

## 三个关键争议

- **严格零空间与阻尼鲁棒性如何兼顾？** 阻尼改善近奇异命令，却让 `I - J#J` 一般不再是严格投影；单独构造 SVD 零空间仍不能保证物理跟踪。
- **RL 的未来规划优势是否存在？** 势场可能足够强，RL 也可能只是对训练布局过拟合。未单独训练去掉 future-reference 的策略时，不能把优势归因于某个输入。
- **“可行且公平”的测试集是谁定义的？** witness 生成器能改变保留下来的场景；单一方法找到的任务可能偏向该方法。需要筛选日志、多个候选方法与诚实的未验证标签。

## 单元 1：工具点速度、Jacobian 与主次任务

### 输入与输出

七个关节位置 `q` 形状 `(7,)`，单位 rad；其速度 `q_dot` 单位 rad/s。工具点世界坐标 `x = f(q)` 形状 `(3,)`，单位 m。位置 Jacobian `J(q)` 形状 `(3,7)`：

\[
\dot x \approx J(q)\dot q.
\]

`J[i,j]` 表示在其他关节固定时，第 `j` 个关节增加 1 rad 所引起第 `i` 个工具坐标的局部变化率，单位 m/rad。它与工具点位置、参考坐标系和关节顺序绑定。同一 link 上换一个偏置工具点，通常必须换 Jacobian。

七个控制关节不等于模拟器只有七个可动自由度。Panda 手指即使被固定目标约束，其 prismatic joints 仍可能出现在 `calculateJacobian` 的自由度列中。必须按实际 joint 元数据建立列映射，不能直接截取未经核验的列。

### 机制：把任务速度变成关节速度

定义位置误差 `e = x_ref - x`，世界坐标、单位 m；期望任务速度：

\[
v_{task}=\dot x_{ref}+K_p e.
\]

第一项前馈跟随已知轨迹运动，第二项纠偏；`Kp` 单位 1/s。`v_task` 形状 `(3,)`，单位 m/s。若 J 满行秩，七维关节速度有多种组合产生同一个三维工具速度。Moore–Penrose 伪逆给出最小欧氏范数的解；近奇异位形时很小的奇异值可能导致过大的关节速度。

阻尼最小二乘候选为：

\[
J^\#=J^T(JJ^T+\lambda^2I_3)^{-1},\qquad \dot q_{primary}=J^\#v_{task}.
\]

`J#` 形状 `(7,3)`；正阻尼换取较小、较稳定的关节命令，也引入不能忽略的任务速度偏差。代码宜用 `solve`，不直接求逆；不能只凭公式正确判断参数合适。

次级命令 `u_secondary` 形状 `(7,)`、单位 rad/s。理想投影可由 `J = U S V.T` 的零空间基 `V_null` 构造：

\[
N=V_{null}V_{null}^{T},\qquad \dot q_{raw}=\dot q_{primary}+Nu_{secondary}.
\]

满行秩时 `rank(J)=3`，零空间通常四维；奇异处维数可能增加，但可用的工具运动方向反而减少。`N` 是 `(7,7)`，满足 `J N ≈ 0` 仅是当前姿态下的数值几何性质。`I - J#J` 只有满足相应广义逆条件才可作为严格零空间投影；阻尼逆通常不满足。

### 假设与失效条件

公式假设工具点和 Jacobian 使用同一坐标约定；运动够小，局部线性化有效；关节速度可以被执行。现实仿真中至少五处会破坏这些假设：

1. link frame 与惯性/质心 frame 混用，或工具偏置错误；Jacobian 可能数值正常但对应错误点。
2. 关节索引与可动自由度列映射错误；矩阵形状对了不等于列含义对了。
3. 小奇异值使逆问题病态；阻尼和速度限制进一步产生任务偏差。
4. 对合成关节速度逐关节裁剪会改变向量方向；裁剪后的次级分量可能不在零空间。
5. 电机力矩有限、惯性、离散步长和接触使测得速度偏离命令；`stepSimulation` 后必须重新读状态。

固定手指意味着不让策略控制它们，并用一致方式维持目标；不意味着删除其碰撞几何。位置任务也不意味着工具朝向静止，朝向变化可能改变手的障碍净空。

### 验证方法

中心有限差分逐列检验工具点 Jacobian：

\[
J^{FD}_{:,j}=\frac{f(q+h e_j)-f(q-h e_j)}{2h}.
\]

`e_j` 是第 `j` 个标准基向量，`h` 单位 rad。应在多个合法姿态与合理的多个 `h` 上检查误差；太大导致截断误差，太小受浮点噪声影响。数值诊断使用状态重置是允许的，但不能证明电机在完整任务时间内执行得了这些姿态。

随后让 `u_secondary = 0`，使用电机推进平滑直线；每个物理步记录 `x_ref, x, q, q_dot, q_dot_raw, q_dot_exec`、误差与饱和。再独立给一个非零次级诊断命令检查 `||J N u||`，避免因为 `u=0` 得到零泄漏而误称已验证投影。只有实际 rollout 满足指定的阶段 1 阈值，才能说本配置下无障碍跟踪通过。

### 常见错误

把 Jacobian 当位置映射；把七个关节与七个模拟器自由度等同；把阻尼投影写成严格保证；把命令速度当实际速度；只检查最后一个时刻；用 `resetJointState` 的动画宣称动态执行通过；用零次级命令的零泄漏证明整个投影实现正确。

### 工程检查清单

- 关节、列顺序、link、局部工具偏置和坐标系均有日志。
- Jacobian 有限差分涉及同一个工具点与多个姿态。
- 非零次级诊断检验投影；数值秩、奇异值与阻尼可追踪。
- 正式 rollout 经电机推进；状态重置只出现在初始化或明确诊断。
- 保存合成命令、实际执行命令和测得速度，记录饱和。
- 参考时钟单调，不因跟踪误差暂停；位置阈值失败不可抹去。

### 最小实践

复跑一次无障碍 smoke test，选取误差最大的时刻，在日志中找出参考位置、实际位置、原始命令、执行命令、实际速度和饱和标志。用三句话解释：误差在哪里形成、哪条证据支持你的解释、还缺哪项证据。不要仅凭单张误差图认定控制器算法有误。
