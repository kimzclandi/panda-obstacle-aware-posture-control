## 1. 研究问题与四类事实

在共享同一个解析末端位置跟踪器的条件下，学习到的次级姿态控制器，能否比调优后的人工势场控制器提高完整轨迹的无碰撞跟踪成功率？优势或失败出现在哪些场景？

| 类别 | 已知内容或边界 |
| --- | --- |

## 2. 范围

策略调整机械臂姿态，不能改参考路径、轨迹时长或暂停参考时钟。位置任务为三维，不控制工具朝向；不做视觉、抓取、实机、ROS、Gazebo、Isaac Sim 或分布式训练。手指不参与策略 action，但碰撞几何仍需包含手与手指。当前以位置伺服保持两个手指关节各 0.02 m；这是固定目标而非刚性焊接，需要记录实际漂移。

第一阶段只实现与验证无障碍模型、几何诊断和主跟踪闭环。无障碍 smoke test 通过不代表避障、场景动态可行性或 RL 已完成。

## 3. 共享控制与测量契约

候选速度级结构：

\[
\dot q_{\mathrm{raw}}=J^\#(\dot x_{\mathrm{ref}}+K_p(x_{\mathrm{ref}}-x))+Nu_{\mathrm{secondary}}.
\]

- `q, q_dot, u_secondary`：七个 arm joints 顺序固定，形状 `(7,)`，单位分别为 rad、rad/s、rad/s。
- `x, x_ref, x_dot_ref`：同一个工具点，世界坐标系，形状 `(3,)`，单位 m、m、m/s。
- `J`：该工具点的位置 Jacobian，形状 `(3,7)`，单位 m/rad；由 PyBullet 的实际可动自由度列映射抽取，不能把 link 索引当成 Jacobian 列号。
- `Kp`：位置误差到速度的增益，单位 1/s；实现可用标量乘单位矩阵。
- `J#`：阻尼逆用于改善近奇异位形的数值行为；`N`：从 SVD 零空间基构造的投影，形状 `(7,7)`，无量纲。
- `q_dot_exec`：经过共享速度限幅后送给速度电机的命令；关节限位由URDF物理约束与逐步失败检测处理，不宣称另有完整安全过滤器；不等同于测得关节速度。最大电机力矩和模拟器响应进一步限制实际运动。

保存原始组合命令、限幅后执行命令和实际速度；分别记录 `||J @ N @ u_secondary||` 和限幅前后主任务速度变化。几何投影正确不能证明离散、限幅、动力学执行后的跟踪或安全。

## 4. 成功判据与报告契约

最终评估成功 = 完成参考时间，且**所有检查时刻**满足以下条件：位置误差不超容差、无禁止碰撞、无关节限位违反。容差与数值边界在 pilot 后冻结，现阶段不能任意宣布为最终阈值。

参考时间随仿真时间单调前进。当前候选步长为 `1/240 s`，每个物理步检查一次；检查覆盖初始化与每次推进后的实际状态。离散检查不保证两个采样时刻之间从未接触。明确记录 contact distance、关节边界 epsilon、允许/排除碰撞对及原因；接触和容差等号边界由代码与配置统一定义并测试。

跟踪误差一旦超容差，本回合失败标志永久置位。即使随后回到轨迹或抵达时限，也不能恢复成功。碰撞/限位可提前终止；位置越界是否立即结束是环境设计选择，但不能撤销失败历史。Gymnasium 中任务定义的结束（包括到达有限时域任务终点）用 `terminated`；外部 TimeLimit 或资源截断用 `truncated`。若后续选择不同 finite-horizon 语义，必须说明 bootstrap 处理，不能只按“时间到”机械分类。

主指标为成功数 / **全部固定评估场景数**，提前失败仍在分母中。辅助指标为碰撞率、逐步位置误差、最小几何净空、命令平滑度、饱和率、决策耗时、已执行时长与失败原因。

- 早失败的短轨迹单独报告；不与完整轨迹混合声称误差或平滑度更优。
- 连续指标的共同完成场景比较标注“条件比较”并报告样本数。
- 分别报告简单/较紧布局和每个训练 seed；训练 seed 波动与测试场景抽样不确定性分开。
- 在线耗时明确计时范围：观测特征、策略网络、控制计算、碰撞/诊断、物理推进可分别测量。渲染不混入 DIRECT 控制耗时。
- 没有独立训练“无 future-reference”策略时，不将收益单独归因于 future-reference。
- 视频展示典型行为，不能代替固定批量评估。

## 5. 分阶段验收

| 阶段 | 验收证据 | 扩大工作前必须解决 |
| --- | --- | --- |
| 1：模型与跟踪 | 名字发现的 arm/finger/工具 link 表；限位；工具点 Jacobian 有限差分误差；碰撞正/负测试和自碰撞排除说明；执行器推进的无障碍直线 rollout；曲线、状态、命令与饱和日志；复跑命令 | 坐标系/工具点一致；Jacobian 列对应；实际执行通过，而非状态重置动画 |
| 2：场景与势场 | 全臂/手几何势场、关节限位次级项；共享评估；每个接受场景有实际 replay 通过的 witness；生成/拒绝日志；validation 调参记录 | 离散 IK 解不等于动态 witness；未找到 witness 标记“尚未验证可行”；检查单一 witness 生成器的场景偏差 |
| 3：Gymnasium/PPO pilot | observation/action/reward 契约；环境检查；失败锁存测试；短训练；checkpoint 保存/加载；独立评估；吞吐与训练耗时 | reward hacking；动作缩放与共享约束；超时语义；不得先启动数小时正式训练 |
| 4：冻结与交付 | 冻结配置和选模规则；train/validation/test 清单；核心三组对照；目标 3 seeds × 至少 100 held-out 场景；报告、视频与答辩材料 | test 不更新归一化、不调参数或难度；资源不足时诚实降低范围并保留原始失败 |

## 6. 场景、数据与可复现边界

场景 ID、split、起始关节、参考轨迹及时间、球心/半径、容差、机器人版本、执行器限制、随机 seed 均可序列化。先确定 split，调参仅用 validation；test 一旦冻结不得用于选择任务难度。任何筛选必须记录候选、拒绝理由、witness 方法与 replay 结果，不能只保存成功候选。

一个实验对应一个独立目录，保存配置、依赖版本、代码版本或源代码快照、随机 seed、场景 ID、逐回合指标、必要逐步轨迹、checkpoint（若涉及训练）和运行命令。不覆盖历史实验。无 Git 时明确标注，而非虚构 commit；后续 Git 初始化也不能把此前实测错误地归于新 commit。
